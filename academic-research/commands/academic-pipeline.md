# Academic Pipeline Prompt Recipe

This is a Codex prompt recipe, not a registered slash command.

```text
$ars-academic-pipeline mode=full
从 Al-Sc-Zr 再结晶抑制机理的研究问题开始，完成文献、证据矩阵、论文规划、写作、审稿、修订和终稿流程。
```

To resume, provide the prior state table and handoff artifacts:

```text
$ars-academic-pipeline mode=resume
从所附 state record 和 handoff envelope 继续；不要重建已经验证的材料。
```
