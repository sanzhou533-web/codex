# Deep Research Prompt Recipe

This is a Codex prompt recipe, not a registered slash command.

Use either of these forms in a task opened at the repository root:

```text
$deep-research mode=lit-review
系统梳理 Al-Sc-Zr 合金中 Al3(Sc,Zr) 析出与再结晶抑制的研究现状，并给出有证据链的 research gap。
```

```text
Use the project skill at .agents/skills/deep-research/SKILL.md in fact-check mode.
Verify the following claims and show the source trail: ...
```

Available modes: `full`, `quick`, `review`, `lit-review`, `three-way-scan`, `fact-check`, `socratic`, `systematic-review`.
